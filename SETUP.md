# Setup Guide: AML Minor Project (IBM/Multi-GNN)

This guide covers setting up and running the Multi-GNN AML benchmark on **Windows (CPU/CUDA)** and **Google Colab (GPU)** using standard `pip`.

---

## 1. Environment Installation

### Base Dependencies
Install all common data, evaluation, baseline, and visualization libraries:
```bash
pip install -r requirements.txt
```

---

## 2. PyTorch and PyTorch Geometric Installation

### (a) Windows Installation (CPU / Local)
Install PyTorch and PyTorch Geometric directly via pip:
```bash
# CPU-only PyTorch:
pip install torch --index-url https://download.pytorch.org/whl/cpu

# PyTorch Geometric:
pip install torch_geometric
```
*(If you have a local NVIDIA GPU with CUDA, install PyTorch matching your CUDA version from [pytorch.org](https://pytorch.org), e.g. `pip install torch --index-url https://download.pytorch.org/whl/cu121`, followed by `pip install torch_geometric`).*

#### Critical Runtime Finding on `torch-scatter` / `torch-sparse` / `pyg-lib`:
- **Static imports**: Importing modules such as `from torch_geometric.loader import LinkNeighborLoader`, `from torch_geometric.nn import GINEConv` succeeds with just `pip install torch torch_geometric`.
- **Runtime Sampling Requirement**: However, when `LinkNeighborLoader` starts fetching batches (`sample_from_edges`), PyTorch Geometric's underlying `NeighborSampler` raises:
  ```
  ImportError: 'NeighborSampler' requires either 'pyg-lib' or 'torch-sparse'
  ```
- **Platform Availability**:
  - **On Windows (Python 3.13)**: Pre-compiled binary wheels for `pyg-lib` are not currently published on PyPI for Python 3.13, and building `torch-sparse` from source requires Microsoft Visual C++ Build Tools.
  - **Recommended Local Windows Setup**: Use a Python 3.10 or 3.11 virtual environment or Conda environment where pre-built wheels for `pyg-lib` or `torch-sparse` exist (e.g. from the official PyG wheel index: `https://data.pyg.org/whl/`).
  - **On Google Colab (Recommended)**: Colab runs Linux x86_64 with Python 3.10/3.11 and CUDA. Simply install:
    ```bash
    pip install torch_geometric
    pip install pyg-lib torch-sparse -f https://data.pyg.org/whl/torch-$(python -c "import torch; print(torch.__version__.split('+')[0])")+cu121.html
    ```

### (b) Google Colab Installation (Free T4 GPU / TPU)
Google Colab comes with `torch` pre-installed. You only need:
```bash
pip install -r requirements.txt
pip install torch_geometric
```

## 3. Dataset Configuration

1. Place the IBM AML dataset outside OneDrive to prevent syncing overhead (e.g. `C:\aml_data`).
2. The folder structure should be:
   ```
   C:\aml_data\
     └── Small_HI\
           ├── HI-Small_Trans.csv             <-- Raw Kaggle file
           └── formatted_transactions.csv     <-- Generated by format_kaggle_files.py
   ```
3. Set the environment variable `AML_DATA_DIR` if your data path differs from `C:/aml_data`:
   - PowerShell: `$env:AML_DATA_DIR = "C:/aml_data"`
   - Linux / Colab: `export AML_DATA_DIR="/content/aml_data"`
   Or update the path in `data_config.json`.

---

## 4. Running the Workflow

### Step 1: Format Kaggle Transactions
Convert the raw transaction file using standard pandas and CSV streaming:
```bash
python format_kaggle_files.py "C:\aml_data\Small_HI\HI-Small_Trans.csv"
```
This generates `C:\aml_data\Small_HI\formatted_transactions.csv` sorted by `Timestamp`.

### Step 2: Export Data Splits for Tabular & GNN Models
Run `export_splits.py` to extract and freeze the train, validation, and test row splits:
```bash
python export_splits.py --data Small_HI
```
This creates:
- `splits/Small_HI_split.npz`: Exact row index arrays `tr_inds`, `val_inds`, `te_inds`.
- `splits/Small_HI_split_summary.json`: Record counts, day boundaries `(i, j)`, laundering ratios, and timestamp bounds.

### Step 3: Run GNN Training
Train the GIN baseline (WandB is disabled by default; add `--use_wandb` to enable online tracking):
```bash
python main.py --data Small_HI --model gin --testing --n_epochs 1
```
